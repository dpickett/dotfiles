# Agent guidance

This is a public [chezmoi](https://chezmoi.io) dotfiles repository. Source files
use chezmoi naming (`dot_` → `.`, `executable_` → sets +x, `private_`, etc.);
edit the source under this directory, not the applied files in `$HOME`.

## Commits

Do not credit the harness or assistant in commit messages. No `Co-Authored-By`
trailer for the agent and no "Generated with…" lines — commits should read as the
author's own work.
